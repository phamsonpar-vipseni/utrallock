# Utral Lock 2.0🪽 — Android WebView

URL: https://utralsensi.freedev.app

## Build
1. Open this folder in Android Studio.
2. Let Gradle sync/install the Android SDK if prompted.
3. Select `app` > `assembleDebug` or Build > Build APK(s).
4. The debug APK will be under `app/build/outputs/apk/debug/`.

Package: `com.utrallock.twopointzero`
Target SDK: 35
Minimum SDK: 23
